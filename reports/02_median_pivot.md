## 2. Kiem tra bat bien (bang chung map cot dung NGU NGHIA)

So cot bang nhau chi chung to map dung **cau truc**. De chung minh map dung **ngu nghia**, kiem tra cac dang thuc noi tai cua CICFlowMeter: neu mot cot bi map lech sang cot khac thi dang thuc se vo hieu o dung nguon do.

**Bat bien: `Average Packet Size / Packet Length Mean == (n+1)/n`** (off-by-one co huu cua CICFlowMeter, n = tong so packet)

| Nguon | So dong kiem tra | % thoa man (sai so < 1e-6) |
|---|---:|---:|
| 2017 | 2,473,618 | 100.000% |
| 2018 | 593,001 | 100.000% |
| 2019 | 291,108 | 100.000% |

- Ti le thoa man thap nhat: **100.000%** (can ~100%; duoi 99% la dau hieu map lech cot).

> Hai bat bien con lai da kiem chung rieng va dat **100.000% o ca 3 nguon**: `Fwd Packet Length Mean == Avg Fwd Segment Size` va `Subflow Fwd Packets == Total Fwd Packets`. Vi chung la ban sao tuyet doi nen cac cot `Subflow *`, `Avg * Segment Size`, `CWE Flag Count` da duoc dua vao `DROP_REDUNDANT`.
